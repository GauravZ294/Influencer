# Influencer Portfolio

A React and Vite portfolio with a splash page and three themed gallery rooms. The room pages use Three.js for the gallery scenes and GSAP ScrollTrigger for scroll-driven motion.

## Run locally

```powershell
npm install
npm run dev
```

Vite prints the local URL. The build command is `npm run build`.

## Media

Image and video files are intentionally excluded from this repository. Add approved media under `public/` using the paths referenced by the page data, or update those paths to match your local files.
